# USB-Camera-Industrial-dimensional-Measurement-UI
基于通用 USB 摄像头开发机器视觉尺寸测量系统与上位机交互软件。项目集成 OpenCV 图像算法，实现图像滤波、边缘检测、轮廓提取、相机标定与畸变矫正，完成像素坐标到物理毫米尺寸的换算；基于 Qt/PyQt 搭建可视化 UI，支持实时视频预览、在线调节算法参数、实时输出测量结果；引入多线程机制解决 UI 阻塞问题，可用于硬币、紧固件等小件样品的外形尺寸测量验证。


# USB相机工业尺寸测量上位机UI
> 基于 PyQt5 + OpenCV 实现的单目机器视觉二维尺寸测量系统，本科大创项目，用于小型平面工件非接触式测量，支持实时预览、相机标定、畸变校正、轮廓检测与尺寸换算。

## 项目简介
本项目以普通USB摄像头作为图像采集设备，依托单目视觉原理，完成平面工件外形尺寸测量。
流程：图像采集 → 预处理滤波 → 边缘检测 → 轮廓提取 → 相机标定与畸变校正 → 像素尺度换算 → 输出毫米级测量结果。
采用多线程架构分离图像采集算法与UI渲染，解决视频流刷新造成的界面卡顿问题。
适用场景：硬币、垫片、紧固件、小型零件等平面工件的外形尺寸检测，可作为工业视觉入门验证平台。

## 核心功能清单
- 摄像头实时视频流预览，支持打开/关闭相机
- 棋盘格相机标定、内参计算、图像畸变校正
- 图像预处理：高斯模糊、灰度化、二值化、形态学操作
- Canny边缘检测、轮廓查找、轮廓筛选
- 固定物距下像素坐标到物理毫米的换算
- 可视化UI面板，参数实时调节，测量结果即时展示
- 多线程解耦，算法运算不阻塞界面
- 测量截图保存，标定参数本地保存加载
